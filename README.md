# Sivan Amram — Portfolio

Personal portfolio site (Hebrew by default, English toggle). A single static
`index.html` — no build step — hosted on GitHub Pages.

**Live:** https://sivanam21.github.io

## Structure

```
index.html            the whole site (HTML, CSS, JS, both languages)
resume.pdf            CV for the "Download CV" button
videos/               project videos
projects/             hosted project demos (Athalta chatbot)
assets/               images used by the previous version of the site
old-site/             previous version of the portfolio (kept for reference)
```
